## Frozen interface for this slice
- `src/desks/landing/deskImages.js`: export `DESK_IMAGES`, a mapping of original reference asset filename to application absolute image path, and `DESK_IMAGE_CREDITS`, an absolute credits path. Asset task may additionally export `DESK_VISUALS` with trusted static copy and image keys per desk. Static visual inputs contain no record counts, source dates or availability assertions. Exact file hashes/credits retained. Page models choose available imagery, not remote user content.
- `src/desks/landing/deskPresentation.js`: supervisor-owned canonical reference mapping. Export `NATIONAL_PRESENTATION` with id/name, hero title as two text lines, description, image/label/heading, and groups `{id,name,short,title:[line1,line2],description,image,modules:[{tier,feature,title}]}`. `feature` is the exact feature-map name; display text is never a route key. Record fields come only from summaries. Also export summary count/availability helpers for shared UI; resource identity prevents duplicate bills.
- Existing `useNationalLanding(features)` remains the loader. `NATIONAL_FEATURES` keeps its current12 ordering and appends5 existing catalogue features. Summaries remain version1 and add a bill `stages` array if supported, never a reference snapshot stage distribution. `aggregateNationalSummaries` retains shared-resource dedup.
- Shared `DeskLandingFrame` props: `presentation`, `summaries` keyed by canonical feature, `onFeature(feature)`, `retry(feature)`, `lang`, optional `toolbar` slot and `metrics` array `{label,value,note,icon}`. It owns selected sector, source filter, detail/data dialogs and motion state; no fetching or access logic. The mini chart receives actual summary aggregates, never static record values. Missing loading/unknown values show an em dash with state.
- Directory belongs to the shell: it receives existing `deskTabs`, `lockedIds`, language and `onDesk`; no new Local tab or persona/access changes. It can show all currently available app desks including unchanged State. Home remains reachable. Open in Terminal calls `onFeature` and closes the dialog; canonical routing and access remain in existing shell.
- Preserve old Global/Law imports while National conversion is underway by moving their legacy shared row/filter exports into a dedicated file and updating their imports. That extraction is behavior-preserving and verified separately. Page agents do not own it.
