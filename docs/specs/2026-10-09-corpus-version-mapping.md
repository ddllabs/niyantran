# Verified alternate bill-document mapping

> **Status: Normative.** Owner requested continuing corpus mapping,2026-10-09. Sequential local implementation and read-only preflight; no new paid ingestion or frontend publication in this phase.

Current production has2,573 indexed documents /72,917 chunks /1,464 covered bill keys.6,829 unstored frozen bill sources already have text, URLs and local bill keys.827 share a bill with another Download PDF version. The worker's exact-URL guard conflates these with wrong-bill links. A bill attachment already supports multiple indexed documents; citations must preserve each source's own PDF URL and version.

Add an opt-in mapping proof for alternate ordinary bill versions. Both source and current Download PDF must independently match the current unambiguous listing's number/year/title/chamber, have distinct supported version roles and exact local pack/original text hashes, pass existing distributed>=90% body checks, and have frozen fetched PDF hashes. Require unique pack identity for both URLs. Gazette/errata/ambiguous/year-exception cases remain held. Wrong year, bill, title, house, role, body or live Download URL must fail. Current exact-URL behavior stays unchanged.

Worker validates proof fields against source metadata, verifies both cached files, and refetches both PDFs before execution; listing guard compares against the proven current Download URL while citations retain the source URL. Same URL with conflicting expected hashes is rejected. Chunking, embeddings, source spans, budgets, capacity/maintenance gates and default bounds remain unchanged.
